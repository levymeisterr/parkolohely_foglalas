# parkolohely_foglalas

A projekt egy egyszerű parkolóhely foglalási rendszert hivatott szimulálni. A felhasználók regisztrációt és bejelentkezést követve kiválaszthatnak egy adott idő intervallumot, ami alatt egy parkoló helyet szeretnének lefoglalni. A rendszer, ha van szabad hely, kioszt nekik egy szabad parkolóhelyet. A felhasználó továbbá képes megtekinteni a parkoló rendszerében lévő összes foglalást, illetve ki tudja listázni a saját foglalásait, azokat le is tudja mondani.

Alkalmazás használata: GitHub repository klónozása --> projekt mappájába való navigálás --> indítás docker compose up vagy docker compuse up --build paranccsal.

English:

This project simulates a basic parking space reservation system. After signing up and logging in, users can select a time interval for which they wish to reserve a parking space. If there is available space, the system assigns them a free parking space. The user is also able to read all the bookings in the system, list their own bookings and cancel them if they want.

Using the application: Clone GitHub repository --> navigate to the project's directory --> start application by using the docker compose up or docker compose up --build command.
